#Overview project details

Included features

- Responsive desktop sidebar and mobile bottom navigation.
- Daily Scripture and devotional dashboard.
- Bible reader with translation, book and chapter selectors.
- Scripture search and topic discovery.
- Verse saving, sharing and prayer action hooks.
- Prayer room with Scripture references and categories.
- Personal prayer journal.
- Daily reading streaks and progress tracking.
- Reading plans and saved verses.
- Your API.Bible ID preconfigured in the reader interface.
